How this works
  1. Your organization connects its own AI account or server here — one you already pay for or run yourself. FunQuote never bills you for AI usage; requests go straight from this server to your provider using your credentials.
  2. Pick a provider below, enter your API key (and base URL for a local/custom server), and save.
  3. Click Test connection — it sends one tiny request to verify your credentials and endpoint work.
  4. Once connected, ✨ AI-assist quoting and bulk catalog import use your provider. Every call is recorded in the AI task log.
Your API key is stored encrypted and only ever shown masked. The AI is never sent your prices and can never write to your data — it only suggests drafts that you review.

Connecting OpenAI
  1. Create an API key at platform.openai.com → API keys.
  2. Paste it above. Model examples: gpt-4o-mini (fast/cheap) or gpt-4o.
  3. Leave Base URL blank unless you use a gateway/Azure-style proxy.
Connecting Anthropic (Claude)
  1. Create an API key at console.anthropic.com → API keys.
  2. Paste it above. Model examples: claude-sonnet-5 or claude-haiku-4-5.
  3. Leave Base URL blank unless you use a proxy.
Connecting Google (Gemini)
  1. Create an API key at aistudio.google.com → Get API key.
  2. Paste it above. Model examples: gemini-2.0-flash or gemini-1.5-pro.
  3. Leave Base URL blank unless you use a proxy.
Connecting your own local or external AI server
  1. Works with any server exposing the standard OpenAI-compatible chat API: Ollama, LM Studio, vLLM, LocalAI, text-generation-webui, or a hosted gateway.
  2. Set Base URL to your server's API root, e.g. http://192.168.1.50:11434/v1 (Ollama) or http://localhost:1234/v1 (LM Studio).
  3. Set Model to a model your server has loaded, e.g. llama3.1.
  4. API key is optional — only if your server requires one.
  5. Make sure this FunQuote server can reach that address on your network.
